This is not a real field in the metadata. It is here to provide the ability to access array types by index instead of by pointer.

§method_specs: Vec<Il2CppMethodSpec>§field_offsets: Option<Vec<Vec<u32>>>

Compiler calculated field offset values. Only exists when read from an ELF. Since this is platform dependent, it cannot be read from C++ sources.

§type_definition_sizes: Option<Vec<Il2CppTypeDefinitionSizes>>

Compiler calculated size values. Only exists when read from an ELF. Since this is platform dependent, it cannot be read from C++ sources.
